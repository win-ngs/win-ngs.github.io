win-ngs

A portal for NGS analysis tools that run on Windows

Original Software Compiled Binaries External Tools About GitHub

Most NGS (Next-Generation Sequencing) analysis tools are built with Linux or macOS in mind, and information about running them natively on Windows is scattered. This site collects tools that work on Windows out of the box, binaries we compiled ourselves, and links to useful external tools in one place.

External Tools

Tools that either run on Windows out of the box or ship official Windows builds. WSL-only tools are tagged separately so they're easy to spot.

QC / Preprocessing

FastQC Read quality checks. Java-based; runs on Windows. fastp Fast read trimming and QC. Build/WSL Trimmomatic Adapter and low-quality base trimming. Java-based.

Alignment

minimap2 Fast aligner for both long and short reads. Build/WSL Bowtie2 Short-read aligner with official Windows binaries. BWA Classic short-read aligner. Build/WSL

SAM/BAM/VCF Manipulation

samtools / bcftools / htslib The de facto standard NGS data toolkit. Build/WSL Picard Tools SAM/BAM manipulation and metrics. Java-based.

Variant Calling / Annotation

GATK The go-to variant calling toolkit. Java core with native deps. SnpEff / SnpSift Variant annotation. Java-based.

Viewers / Visualization

IGV (Integrative Genomics Viewer) Visualizer for BAM/VCF/BED. Windows installer available. Tablet Lightweight read viewer. Windows-friendly.

Build Environments / Runtimes

MSYS2 Build environment on Windows. Many NGS tools compile here. WSL2 The practical answer for running Linux-only tools.
